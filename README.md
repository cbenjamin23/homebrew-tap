# Homebrew tap

Homebrew formulae maintained by Charles Benjamin.

## alog2media

Install the headless MOOS-IvP log scene exporter on macOS or Linux:

```bash
brew install cbenjamin23/tap/alog2media
```

The formula builds the tagged `alog2media` release and its pinned MOOS-IvP
build dependency from source. A MOOS-IvP checkout is not required after
installation.

Project source and documentation:
[cbenjamin23/alog2media](https://github.com/cbenjamin23/alog2media).
